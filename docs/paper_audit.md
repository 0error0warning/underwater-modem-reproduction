# 原论文与实验口径核验

核验日期：2026-11-02。核验对象：Schmidt 等，*Performance of low-power underwater modem for shallow water communications*，DOI [10.21008/j.0860-6897.2024.2.07](https://doi.org/10.21008/j.0860-6897.2024.2.07)。[官方 PDF](https://vibsys.put.poznan.pl/_journal/2024-35-2/articles/vps_2024207.pdf)已全文提取，并将第 3、7、8、9 页渲染后逐项目视核对。以下页码均为 PDF 页码。

本项目可复现 BFSK 与保护时间的机制和有限配置；目前不能声称精确复现全文所有数值。论文未充分披露具体双音频率、采样率、FFT 长度/窗、噪声归一化、数据量/随机种子、信道文件选择与包放置、接收同步细节。正文给出 250 Hz 频率间隔；13,875/14,125 Hz 与 48 kHz 是本项目的明确实现假设，后者与图中采样点数量相容，但不是论文直接报告的采样率。

## 1. 原文符号存在歧义

- 第 3 页公式 (1) 的发射区间为 `(n-1)Ts <= t <= nTs-Tg`，图 3 也把 `Ts` 画为含静默时间的周期。但第 8 页表 3 使用 `Ts=Tg`，图 6 又明确有非零发射脉冲。若机械代入公式，发射时长会变为零。本项目采用 `on_ms` 表示有效发射时间、`guard_ms` 表示额外静默时间，周期为两者之和。这是结合实验图表作出的解释，不把它冒充原文一致无歧义的定义。
- 第 9 页 FFH 正文测试的是跳时 `Th={4,8,16} ms`，表 4 表头却写 `Ts`；第 4 页给出 `Ts=L*Th`。后续实现必须分别命名 `hop_s` 与 `symbol_s`，不能直接按表头把 8 ms 当成整比特时间。
- 第 8 页表 3 标题括号写 `SNR=20dB`，表内实际上包含 20、10、0 dB 三组。参考 CSV 保留表内所有行。

## 3. 两种噪声口径必须分列

[Watermark 官方](https://www.ffi.no/en/research/watermark)原始 `sfetch.m` 将参数 `SNR` 明确解释为 `Eb/N0`，其噪声方差等价于：

```
sigma2 = sum(y_clean.^2) / (2 * N_info * 10^(EbN0_dB/10))
```

论文只写 SNR，未说明是否调用了这一接口。非相干正交 BFSK 的理想 AWGN 参考为 `Pb=0.5*exp(-Eb/N0/2)`，在 `Eb/N0=0 dB` 时约为 0.3033；表 3 的 0 dB 行却可到 0.0032。因此不能自动将论文标签等同于此定义。这一差异提示需核查噪声口径，不能单凭它确定作者用了什么代码。

建议并列保存两条明确命名的结果：`ebn0_db` 按官方方差公式；`sample_snr_db` 按 `sigma2=mean(y_clean.^2)/10^(SNR_dB/10)`，并记录参与均值的样本区间。若同一能量统计区间长为 `L`，包含 `N_info` 信息比特，则上述两种定义有：

```
EbN0_dB = sample_SNR_dB + 10*log10(L/(2*N_info))
```

例如无保护、无前导、无尾部且每比特 384 个样本时，相差约 22.83 dB。两种结果不能共享一个没有解释的“SNR”轴，也不按接近原表的程度事后挑选口径。

若整包均值包含保护静默，增加保护时间还会降低所加入的噪声。为研究保护时间本身的公平收益，应另外保持有效发射幅度及噪声方差不变，或明确报告这样的能量/功率口径差异。若有前导，`N_info` 是否仅指载荷、前导能量是否计入 `Eb` 均须记录。

## 4. 接收与统计边界

论文第 2 页采用 HFM-UP/HFM-DOWN 前导；自行添加 BFSK 训练序列属于本项目实现选择。接收定时可由训练前导估计，但不得通过载荷真值或最低 BER 反选定时。已知包边界或已知信道参数的对照应明确标注，不能称作已经实现自动捕获，也不自动等于严格性能上界。

官方 `sfetch.m` 会按 `1/(1-V0/1500)` 重采样恢复整体多普勒；直接调用 `replayfilter` 后若省略此步骤，会改变官方信道语义。采用 MAT 缓存可以保留原回放内核，但应记录与官方包重复、WAV 存储及随机包偏移的差别。

每个配置至少记录信道文件/时间段、数据与噪声种子、错误比特数、总比特数、包数、发射时长、开销与速率。AWGN 独立比特可报告二项置信区间；实测时变信道中的位错误和相邻包可能相关，三段信道不能当成大量独立信道样本。先报告分文件 BER 与范围，必要时按包/信道段做区块重采样。`R*(1-BER)` 只是正确比特率代理；真正分组 goodput 应依据整包成功率和总时间计算。

## 5. R2020b 的 WAV 32 位写入实测

2026-11-02 在本机 MATLAB R2020b 中，用 `audiowrite(...,'BitsPerSample',32)` 将列向量 `[-2;-1;-0.5;0;0.5;1;2]` 写入临时 WAV，再用 `audioread` 读取。读回值完全一致，最大绝对误差为 0，没有写入警告，文件信息为 32 bits/sample；临时文件已删除。这个探针说明该环境下这组 32 位浮点输入未被裁剪，不外推到其他位深、版本或所有信号。官方 shell 的 RMS 归一化因此不能仅凭峰值超过 1 就判定已损坏。
