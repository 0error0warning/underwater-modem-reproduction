# V2 接收同步、多普勒与自适应保护时间：独立协议审查

审查日期：2026-11-02。此文件记录原文核查、预先约定的实验边界和待执行检查，不宣称 V2 已通过实验。只更新本文件，保留 V1 结果及其局限。

## 一、原文究竟给了什么

主论文为 [Schmidt 等，2024](https://vibsys.put.poznan.pl/_journal/2024-35-2/articles/vps_2024207.pdf)，本地文件 `references/vps_2024207.pdf`。页码为 PDF 页码。

|项目|确切来源与内容|不能据此推定的参数|
|---|---|---|
|HFM 前导|第 2 页及图 1：HFM-UP/HFM-DOWN 脉冲对后接数据，引用文献 [4]、[6]|没有脉冲时长、脉冲间隔、扫频端点、重复对数，也没有说明表 2/3 是否包含真实前导捕获|
|BFSK 频率|第 6 页：间隔 250 Hz，名义 BFSK 带宽 500 Hz；14 kHz 是所用信道中心，第 4 页也是系统示例中心|没有给两音绝对频率、比特到频率的具体映射；图 3 的 f0…f15 只有编号、没有 Hz 刻度|
|FFT 检测|第 4 页：模拟下变频至基带、加窗、DFT/功率谱、窄频带 Ym 最大值判决；第 6 页：FFT 使用 Ts 内的 N 个采样，FFH 则使用 Th 内采样|没有实际采样率、下变频本振、窗型、补零长度、频带边界、频带内求和/取峰等完整实现|
|相位|第 3 页公式 (1) 将相位称为未知随机相位，第 4 页 FFH 公式也有未知随机相位|没有给随机化方式、每符号重置/连续相位策略或随机种子|
|同步与统计|前导概念单独说明；第 6-9 页直接给 BER 测试和结果|没有捕获阈值、定时误差容限、失锁包的 BER 处理、发送比特数、包长、所用信道文件与噪声实现|
|SNR|表 2/3 给出 0、10、20 dB 标签|没有确认这是采样功率 SNR、接收端 Eb/N0，还是其他定义；不能因使用 Watermark 就认定调用了 sfetch 的加噪接口|

`Ts/Tg` 与 FFH `Ts/Th` 的原文歧义仍然存在，详见 `docs/paper_audit.md`。本项目继续使用 `active_duration` 与 `guard_duration` 分别命名，避免含义混淆。

### 引用论文补充了前导参考，但没有补出 BFSK 双音位置

2024 年文献 [6] 的 [2023 同步论文](https://vibsys.put.poznan.pl/_journal/2023-34-1/articles/vps_2023102.pdf)第 2 页给出标准结构：`HFM-UP(Tps) -> 静默 Tg -> HFM-DOWN(Tps) -> 静默 Tg -> 数据`。第 3 页示例 `Tps=64 ms, Tg=64 ms`；第 4-5 页测试 `Tps={1,4,16,64} ms`，文字列出 `Tg=16/64 ms`。表中 BT 可推出 5 kHz 扫频带宽，但这些不能追认为 2024 年 BER 实验的确切前导参数。

文献 [4] 的 [Sensors 2023 唤醒接收机论文](https://www.mdpi.com/1424-8220/23/4/2088)讨论 HFM 匹配滤波和 CA-CFAR，给出 5 kHz 基带及 10 kHz ADC 的前导接收实现，仍未提供 2024 BFSK 的两音映射。其水池实验使用不同频段硬件，不能直接移植为本项目的 14 kHz 数据调制配置。

可实施的前导起点是：48 kHz 带通采样、一个 64 ms HFM-UP 与一个 64 ms HFM-DOWN、16 ms 或预先固定的较长静默间隔、5 kHz 扫频带宽放在 Watermark 10-18 kHz 可用带内，例如 11.5-16.5 kHz。**这些是参考前作后自行指定的参数，必须在配置中冻结并标明来源，不是主论文已披露参数。**

两篇 2023 论文印刷的多普勒表达式按字面为 `[(Delta_t_UPDOWN-Tg)/2]^-1`；代入无多普勒的普通脉冲间距不能自然得到零频移，不能不经验证直接实现。HFM-DOWN 也应显式交换起止频率，确保瞬时频率确实从高端降至低端。推荐由已知前导做时间尺度模板匹配，通过无速度、正速度、负速度的合成信号确认符号和量纲。

## 二、FFT 对齐敏感性必须与改频效应分开

现有两音 13,875/14,125 Hz 在 4 ms 观测窗中分别为 55.5/56.5 个周期；以 14 kHz 复数下变频后是 +/-125 Hz，而 N 点 DFT 间隔为 250 Hz，确实落在半 bin。8/16/32 ms 时不存在相同的半 bin 问题。这不意味着 V1 的精确频率正交匹配检测有错，也不能证明作者使用了另一对频率，因为原文连模拟本振都未交代。

在最终测试前固定以下敏感性集合即可：

|候选|频率 Hz|用途|
|---|---|---|
|对称原配置|13,875 / 14,125|保持与 V1 连续|
|较低的一组整 bin 配置|13,750 / 14,000|观察频率放置及整 bin 条件的影响|
|较高的一组整 bin 配置|14,000 / 14,250|同上，避免只挑某一侧较好结果|

先在同一发送波形上比较精确双音能量与明确声明窗、FFT 长度、频带边界的 FFT 检测；再讨论三种发送频率。改频也改变实测信道的频率选择性衰落，不能把全部性能变化归因于 bin 对齐。补零只能细化频谱采样，不能凭空提高观测时长所决定的分辨能力。频率和检测器的主配置不得根据 31-40 记录或“更接近原表”的结果反复挑选。

## 三、同步和多普勒的边界

接收函数只接受接收到的波形、采样率、预先公开的帧格式/前导/训练序列和已冻结的接收配置。`h`、`V0`、注入包起点、载荷真值、最佳候选模式只能留在信道生成或评分模块，不能作为接收或自适应策略输入。

1. 信道生成端按官方 `sfetch` 的语义，用 `alpha=1/(1-V0/1500)` 恢复整体时间伸缩。压力测试需声明 +/-0.5、+/-1.5 m/s 是总速度还是叠加偏置；若分两次重采样，尺度相乘，不能混淆为未说明的速度相加。压力测试是对实测 TVIR 叠加的整体尺度扰动，不是新采集的运动海试数据。
2. 在完整监听窗口内加入未知包起点；不能先按真实起点裁剪一小段，再声称完成未知起点搜索。时移零填充不得改变噪声定标：整包信号功率/能量应在加入监听静默前计算，不能随机静默越长噪声越小。
3. 时间和尺度从收到的 HFM/已知训练信息估计。用匹配能量或联合脉冲匹配，避免把单条多径峰切换误认为速度变化；随机载波相位也应通过合成验证。搜索范围、格点、阈值、失锁处理先在训练/验证集合固定。
4. 必须包含纯噪声窗口，报告假警数/窗口数或监听时长。不能对每个窗口无条件返回最高峰，然后把“总能返回位置”当成捕获成功。纯噪声试验的方差使用同一噪声参考，不能因不存在信号而被计算成零。
5. 评估分开报告捕获率、假警、已正确关联包的条件 BER、全部发送包的 PER、同步丢失/擦除数和含开销的无错载荷率。漏检不应从 PER/goodput 的分母消失；也不把漏检包直接按 128 个实际错误位默默混入普通 BER。
6. 定时/尺度真值只用于事后评分。多径下“第一到达”与“最强到达”不同，时间误差的参考定义必须预先说明；不能按哪种参考让误差最小而更换标准。

## 四、训练、验证和最终测试

已约定每个信道的 1-5 记录用于训练，6-10 用于验证，11-30 不使用，31-40 作为最终时间留出集合。1-10 在 V1 已被查看，因此 6-10 不称为全新独立最终测试。31-40 相隔更远能减少紧邻时间泄漏，但仍是同一测量序列，不代表跨海域或跨设备泛化。

最终测试前应保存参数与策略文件、训练/验证记录编号、随机种子和候选频率/速度/噪声集合。不能在看过 31-40 的结果后继续调门限，却仍把它作为未见测试。若因实现错误必须重跑，保留错误原因和变更记录；若研究选择发生变化，应另设新的最终留出段。

三种噪声口径继续分列。固定噪声主比较在同一信道记录内固定参考与方差，不能随候选保护时间重新计算噪声；跨记录重新定标的事实仍须披露。最终测试的训练标签、误码数和反事实最佳模式不得回流到策略选择中。

## 五、自适应保护时间：因果顺序和公平成本

已采用一包延迟方案：第 n 包选择只使用第 n-1 包实际收到的前导/训练特征及可用反馈，不能根据当前载荷的真实错误情况挑选当前保护时间。第一包采用训练阶段确定的默认策略，捕获失败时使用预定回退方式。接收端特征可以是相关峰形状、晚到能量比例或已知训练符号质量，但不能把真实 TVIR 的时延扩展伪装成在线估计结果。

逐包重放所有保护时间候选以获得反事实结果是可用的离线评估方法。策略应在看见当前包候选结果之前选定动作；事后逐包最佳候选只作为标注清楚的 oracle 参考。建议同时列出全部固定保护时间及仅在训练集选出的最佳固定策略，避免按测试集挑一个较弱基线。

反馈是理想低速控制通道假设，尚不是已实现的反馈物理链路。必须明确反馈字数/空口时长、等待时间、传播或处理时延，并将其加入自适应策略成本；固定策略不需要的反馈成本不能无端强加给基线。若反馈尚未到达，下一个数据包不得使用未来才收到的信息。

**反事实共同时间轴与实际吞吐量不能混用：**若为了公平信道采样，所有候选都在共同的固定时隙起点重放，则实际 goodput 的分母必须包含时隙等待和空闲。另行按“所选包的空口时长 + 控制成本”求得的比值可以作为反事实效率估计，但不能称为该固定时间轴上实现的吞吐量。连续发送且按模式改变下一包时刻的策略，需要单独重放其真实时间线。

自适应改进是否成立由冻结策略后的测试结果决定，可以出现仅降低 BER、速率没有提高或不及最佳固定策略的结果。统计以文件/时间块为主要单位，报告各段结果和总计；不同位、相邻包和相邻记录不假定为独立新信道样本。零错误或零假警均报告观察计数及样本量，不声称真实概率为零。

## 审查结论

这条 V2 路线可直接实施：补全基于收到前导的接收过程，恢复官方整体多普勒，明确频率/FFT 敏感性，再用时间留出数据评估带因果延迟和成本的自适应策略。上述工作能够增强与原研究的可比性，但原文缺失的参数不能由“曲线接近”替代证据；最终应分别标示原文已知条件、自行指定条件和扩展研究结果。
