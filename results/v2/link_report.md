正式结果已完成：固定槽实验使用 NOF1/NCS1 的留出记录 **031–040**，共 1500 个匹配事件、4500 行接收模式结果；连续实验也使用这 20 条记录，共 **595 个发送帧**，每个策略每条记录的计时分母固定为 **完整 32 秒**。开发记录 001–010 仅以 20 dB 结果作背景，未与留出结果混合。smoke 未进入本报告。

完整 32 秒连续实验的跨信道合计速率为：冻结固定策略 **11.4 bit/s**，冻结自适应策略 **10 bit/s**。这次运行没有观察到自适应的吞吐优势；不能仅凭条件 BER 或 PER 改善宣称吞吐改进。这两种冻结策略在 NCS1 的连续运行均未得到完全无错的整包；这与前导是否被捕获是不同指标。

## 统计口径与范围

- 条件 BER = 实际比特错误数 /（发送载荷 bit 数 − 擦除 bit 数）。未得到完整载荷的包保留为捕获损失、128 bit 擦除和包错误；不会把它算作零误码。若完全没有判决，条件 BER 为 NA。
- `capture_loss` 是未输出完整载荷的比例，并非通过真值确认的独立定时关联失败率。PER 包含捕获失败和至少一个载荷错误的包。
- 无错载荷速率只计整包完全正确的载荷 bit。固定槽分母包含所有 6.4 s 监听槽；连续分母每个策略/信道/记录只计一次 32 s，含启动、反馈、取整和末尾空闲。这里不使用“占用时间效率”代替真实排程速率。
- 尚无 CRC/ARQ 协议。整包是否正确由离线载荷真值统计，故速率是**理想无错载荷统计值**，不是已实现的接收确认吞吐量。策略和接收器不读取这份正确性真值。

零误码观测也不意味着真实 BER 为零。这里保留计数与分母，未把相关的比特或包机械当成独立海况样本。

本轮横轴是固定参考接收功率的 **样本 SNR**：`variance = calibrationPower / 10^(SNR/10)`。8 ms、48 kHz 的 BFSK 参考换算与载荷有效能量的 `Eb/N0` 相差约 **22.83 dB**。因此本报告的 0/10/20 dB 不能直接当作 AWGN 自检或官方 `sfetch` 的同值 `Eb/N0`，也不能据此宣称精确复现原文同名 SNR 条件。每条记录单独校准一次，并在保护时间和策略之间固定噪声功率。元数据原说明：`One independent 8 ms/no-guard receive-active-power reference per recording; fixed across guard`。

## 真正连续排程的结果

每发一个包，下一次发射时刻前进“所选完整帧长 + 128 ms 公共尾段 + 0.160 s 控制预算”，并在新的绝对 TVIR 时间回放信道。随机接收窗口前置背景只用于未知起点，不作为发送空闲或重复加入时间分母。不同策略共享按绝对观察时间索引的噪声序列；包数和发送时刻可以不同。

## 接收机验证与解释边界

接收机自检 `PASS`：必需项 71/71 通过；纯噪声误检 0/50。零次观察的单侧 95% 上界为 5.82%，不能把配置中的 0.1% 设计目标说成实测误检率。另有 3 个 `Eb/N0=0 dB` 压力样本，仅捕获 0 个；它们未被隐藏，也未作为要求零误码的自检。该 dB 定义与本报告样本 SNR 不同。

另有一组**独立合成单径长包压力测试**，不参与策略拟合或真实信道统计：512 bit、未知相位与起点、20 dB 有效发射期样本 SNR，分别使用 −1.5/0/+1.5 m/s。它演示较长数据块累积漂移时补偿器的能力，不代表实测水声多径中的性能。
