# 弱早径、晚强径与 4 ms 相位重置：独立机制验证

此目录只验证一个可能机制，不以合成通道替代 NOF1，也不把合成结果当作原论文参数的证据。没有修改冻结接收器、自适应策略或最终测试。主 V3 诊断中发现的 MATLAB `pi` 遮蔽不影响这里：本脚本用 Python 的 `np.pi`。

## 文件与复验

- 实现：`tools/diagnose_weak_early_phase_v3.py`。运行 `python tools/diagnose_weak_early_phase_v3.py` 可重新生成本目录三份 CSV/JSON。
- `weak_early_phase_timing.csv`：完整 768 行结果。
- `weak_early_phase_timing_paired.csv`：完整 192 行配对结果，4 ms 与 8 ms 各 96 个路径配置。
- `weak_early_phase_timing_validation.json`：种子、完整计数、自检结果及例子选择规则。

预先列出的路径网格为：晚径延迟 0.75/1/1.25 ms × 早径幅度 0.2/0.4/0.6/0.8 × 晚径相位 0、π/4、…、7π/4，共 96 个配置；晚径幅度固定 1。每个配置均测试 4/8 ms、逐符号同相重置/连续相位、早径起点/晚强径起点，故总计 96×2×2×2=768 行。频率 13,875/14,125 Hz、采样率 48 kHz，无加性噪声，真实尺度固定 1。

随机种子为 2026110210，共生成 1024 bit；两端各舍去 8 bit，避免有限长 Hilbert 解析信号构造的边界影响，每条件评分 1008 bit。两种相位使用相同载荷、初相 0.7 rad；早/晚时间窗和真实尺度均明确给定。真实通道未知到达时刻的估计误差不在这个 toy 中。

## 完整网格观察

4 ms 的 96 个路径配置中，49 个配置出现重置相位时早径窗错误数高于晚强径窗；49 个配置出现早径窗下连续相位优于重置相位。8 ms 下两种相位的波形相同，全部 96 个配置在相同时间窗的判决一致。

例如预设网格中的早径幅度 0.2、晚径幅度 1、延迟 1 ms、晚径相位 π：重置相位早径窗为 515/1008 个错误，改用晚强径窗为 0/1008；连续相位两个时间窗均为 0/1008。完整表保留全部配置，不能把这个例子当作 NOF1 的拟合模型。JSON 中列出的另外几个例子是按网格内错误差排序选出的演示，选择规则已公开。

这里两径通过实信号的解析表示施加复增益，再取实部接收，模拟相对路径相位。实际 Watermark 具有频带限制、多个时变路径与不同路径幅相，真实 NOF1 不一定等同此双径 toy。改变相位约定并不保证所有通道、时间窗或 BER 都改善。

## 相消公式的适用条件

以下是**复单径、相邻两个符号为同一个比特、矩形积分窗、无噪声及无频率/尺度误差**的理想模型，不是完整实信号多径 BER 公式。

设符号时长 T，且 `f*T` 是半整数。每符号从同一相位重启，使相邻符号相对于全局连续载波相差 π。若接收积分窗比该路径的符号起点早 δ，`0 <= δ <= T`，窗口前 δ 时间来自前一符号，后 T−δ 来自当前符号。即使两符号比特相同，两段解旋后的复相关也反号：

```
C_reset(delta) = h * exp(j*(phi - 2*pi*f*delta)) * ((T-delta)-delta)
               = h * exp(j*(phi - 2*pi*f*delta)) * (T-2*delta)
```

因此相对于该路径正确对齐的相关，幅度比例为 `abs(1-2*delta/T)`，能量比例为 `(1-2*delta/T)^2`。T=4 ms、δ=1 ms 时分别是 1/2 和 1/4；连续相位的同一比特两段同号，其幅度为 `abs(h)*T`。这也解释为何弱早径诱导的过早时间窗，可能与 4 ms 相位重置共同削弱晚强径的正确频率积分。

对 8 ms，两音的 `f*T` 为整数，重置与连续相位之间没有上述 π 反号。若相邻比特不同、存在多个路径或误差，上式不能直接给出 BER；必须看完整接收波形与逐路径相位。

## 对实测诊断的用途

优先在同一收到的波形上固定已估尺度，仅比较 HFM 首个显著到达与 HFM 联合相关最强到达，然后固定时间起点只替换尺度。相位对照则应保持初相、比特、噪声及前导相同，最好也复用同一时间起点和尺度；PDP/真实尺度分支只作为带真值的诊断。只有实测受控消融才能说明各因素对 NOF1 偏差的贡献。
